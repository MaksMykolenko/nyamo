# Nyamo Landing Page («Нямо — Смачне з того, що є»)

Сучасна, швидка та адаптивна презентаційна вебсторінка для кулінарного Android-додатку **Nyamo**.

Сторінка розроблена у точній відповідності до фірмового кулінарного стилю додатку (кремовий фон `#FFF9F4`, поверхні теплого молока `#FFFEFC`, коралово-помаранчеві CTA `#EE6E4A` та тепла кавово-шоколадна типографіка).

---

## 🌟 Ключові можливості та блоки сторінки

1. **Головний Hero-блок:**
   - Чітка ціннісна пропозиція з акцентом на 100% офлайн, приватність та безкоштовний доступ.
   - Реалістичний 3D-мокап смартфона з реальними скріншотами та інтерактивними літаючими плашками інгредієнтів.
   - Дії: пряме завантаження APK, виклик інтерактивного демо та запит на Google Play Beta.
2. **Інтерактивний симулятор RecipeMatcher:**
   - Працює безпосередньо у браузері без сторонніх бібліотек.
   - Можливість обирати інгредієнти (яйця, помідори, сир, картопля, борошно тощо) або готові набори («Сніданок», «Деруни», «Сирна паста»).
   - Миттєвий перерахунок статусів у реальному часі:
     - `🟢 Можна приготувати`
     - `🔴 Бракує: 1 інгредієнт` (з конкретною підказкою нестачі)
   - Модальне вікно з детальним рецептом, покроковим процесом та перемикачем порцій (2 / 4 порції).
3. **Bento Grid Переваг:**
   - 6 сучасних карток переваг: алгоритм RecipeMatcher, AI-розпізнавання з Google Gemini, Комора постійних запасів, покроковий фокус-режим, офлайн-база Room SQLite та динамічний перерахунок порцій від 1 до 10.
4. **Інтерактивна вітрина екранів (Showcase):**
   - 6 табів із демонстрацією реальних скріншотів Google Play у високій роздільній здатності (1080×1920).
5. **Галерея страв каталогу:**
   - Справжні домашні страви з соковитими WebP-фотографіями (український борщ, сирники, деруни, шакшука, паста болоньєзе, куряче філе тощо).
6. **Порівняльна таблиця «Чому саме Nyamo?»:**
   - Наочне порівняння зі звичайними кулінарними сайтами (відсутність пейволів на рецепти, робота без інтернету, відсутність потреби купувати 15 нових продуктів).
7. **Багатомовність та автовизначення регіону (i18n):**
   - Автоматичне визначення мови відвідувача: за URL-параметром `?lang=`, збереженими налаштуваннями (`localStorage`), мовами браузера (`navigator.languages`) та часовим поясом (`Intl.DateTimeFormat`).
   - Підтримка 3 мов: **Українська** (`uk`, за замовчуванням), **English** (`en`), **Türkçe** (`tr`, цільовий ринок закритого тестування).
   - Елегантний селектор мов у шапці та в мобільному меню.
   - Повний динамічний переклад усіх блоків, симулятора інгредієнтів, рецептів та модального вікна без перезавантаження сторінки.
8. **Блок завантаження:**
   - Пряме посилання на перевірений файл `Nyamo.apk` (13.4 МБ, Android 8.0+).
   - Векторний QR-код для швидкого сканування камерою смартфона.
9. **Інтерактивний FAQ-акордеон:**
   - Відповіді на ключові питання щодо офлайн-роботи, безпеки фото, ціни та алгоритму.
10. **Підвал із політикою конфіденційності:**
   - Посилання на локальну політику `privacy-policy.html`, контакти та інформацію про розробника NeoFlux.

## 🚀 Як відкрити та протестувати локально

### Варіант 1: Через будь-який браузер напряму
Просто двічі клацніть або відкрийте файл у браузері:
```bash
open landing/index.html
```
Щоб перевірити конкретну мову:
```bash
open landing/index.html?lang=en
open landing/index.html?lang=tr
```

### Варіант 2: Локальний вебсервер Python (рекомендовано)
```bash
python3 -m http.server 8080 -d landing
```
Після цього відкрийте у браузері: [http://localhost:8080](http://localhost:8080)  
Для тестування локалей:
- [http://localhost:8080/?lang=uk](http://localhost:8080/?lang=uk)
- [http://localhost:8080/?lang=en](http://localhost:8080/?lang=en)
- [http://localhost:8080/?lang=tr](http://localhost:8080/?lang=tr)

## 🌐 Деплой

Сторінка створена як статичний вебсайт без бекенд-залежностей і може бути миттєво розгорнута на:
- **GitHub Pages:** увімкніть публікацію з гілки або папки `/docs` чи репозиторію.
- **Vercel / Netlify / Cloudflare Pages:** вкажіть Root Directory як `landing`.
- **Render Static Site:** створіть новий Static Site та підключіть каталог `landing`.
